### 录制与回放调试会话

**录制：**
1. 启动 ABAP 调试会话（见视图与工具中的调试）
2. **Ctrl/Cmd+Shift+P** → **ABAP Replay: Start Debug Recording**
3. 调试——每一步都被捕获
4. **Ctrl/Cmd+Shift+P** → **ABAP Replay: Stop Debug Recording**
5. 保存 `.abaprecord` 文件

**回放：** **Ctrl/Cmd+Shift+P** → **ABAP Replay: Replay Debug Recording**
- 前进**和**后退步进
- 无需 SAP 连接
- 与队友共享
